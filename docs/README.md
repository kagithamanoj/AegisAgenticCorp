# AegisCorp Documentation Hub

Welcome to the AegisCorp documentation. This directory serves as the centralized source of truth for the architecture, agent roles, and operational guidelines of the AegisCorp system.

## Directory Structure

*   **/aegiscorp**: Contains documentation regarding the core system architecture, UI/UX design philosophy, routing setup, and the analytics/metrics backend.
*   **/agents**: Contains documentation defining the roles, responsibilities, and system prompts of the autonomous AI specialists in the squad.

## System Overview

AegisCorp is a React/Express application designed to manage a fleet of autonomous AI agents powered by the Minimax M2.5 LLM. The system treats the user (Manoj) as the CEO/Commander, interacting with the squad head (Monica) and various specialists via a "Mission Control" interface.
